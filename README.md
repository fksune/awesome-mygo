[MyGo](https://mygo.egoist.dev/) is a Go toolkit for building fast, lightweight desktop applications for macOS, Windows, and Linux from a single codebase, with native GPU-rendered interfaces, system webviews, or both. It includes typed IPC, desktop APIs, installers, auto-updates, and more, everything ready to use out of the box.
